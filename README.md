# FinTrust Digital Bank — Week 2 Data Analytics

## AnalystLab Africa Experience Lab

This repository contains my Week 2 Data Analytics work for the FinTrust Digital Bank project as part of the AnalystLab Africa Experience Lab.

Week 2 focused on moving from the planning and business-understanding stage established in Week 1 into practical data analysis and preparation.

## Key Sample Findings

- 33 customer records were reviewed.
- 33 transaction records were reviewed.
- Total transaction value in the supplied sample was NGN 959,180.43.
- Mobile App accounted for 42.4% of transactions.
- Everyday was the largest visible customer segment.
- A Customer_ID relationship issue was identified between the supplied customer and transaction datasets.

## Data Quality Note

Only 1 of the 33 transaction Customer_IDs currently matches the visible customer dataset. The remaining 32 transaction records could not be reliably linked to the visible customer records.

This limitation was documented rather than forcing customer-level conclusions from an unreliable relationship.

The supplied datasets are synthetic and are used for educational purposes as part of the AnalystLab Africa Experience Lab
